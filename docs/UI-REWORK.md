# 琉璃 UI 改版：部署与验收

适用目标：Windows QQ 9.9.36-53644（64 位）、SnowLora 0.3.0+。最新测试版本：`1.3.5+snowlora.6`。

## 改动范围

| 区域 | 处理 |
| --- | --- |
| 主窗口隐藏控件 | 左侧导航按当前侧栏、群成员栏和聊天最低宽度计算让位；顶部常驻 44px 标题空间，不再悬停时逐帧改变整页布局。顶部感应根据向上移动方向或顶边短暂停留触发；资料胶囊常态靠左，导航展开时才让位；失焦进入子窗口时保持展开，返回后恢复自动收起。Electron `no-drag` 命中规则保持原有实现。 |
| 菜单与群资料 | 共用颜色、透明度、模糊、圆角、边缘高光、阴影和动效令牌；浮层透明度令牌与滑块同在 `body` 计算，修复低透明度设置下浮层仍接近实底的问题。群资料抽屉只在外层绘制玻璃，内部卡片改为透明。 |
| 群成员 | 标题、管理员数量、搜索入口分成两行；管理员及群主标记保留文字识别，移除连续大底框。 |
| 置顶会话 | 保留数量、图钉、折叠与选中态；停止生成整组背景元素，减少滚动时的几何测量，并以细色线轻微区别普通会话。 |
| 聊天 | TG 昵称与头衔重新参与气泡宽度计算；新消息提示移除错误命中的空占位框；输入区改为单层半透明磨砂，文字气泡使用受上限保护的材质模糊，QQ 皮肤与媒体消息维持专用渲染。 |
| 搜索 | 独立 Electron 搜索窗口按标题/路由识别；仅在过大的初始尺寸下缩到工作区内，搜索页样式限定到 `data-liuli-scope="search"`。会话列表中的搜索结果层沿用外层玻璃，只补轻色与边缘，避免磨砂叠加。搜索、过滤、结果和跳转仍交给 QQ 原生实现。 |
| 配色与设置 | 新增壁纸自动取色、HEX、取色器及恢复默认；旧 `liuli-color-roles` 和 `liuli-dsh-settings` 保持兼容。设置页去除多层背景，并加入实时模糊预览。 |

## 安装与版本核对

1. 退出 QQ，并备份当前 `assets/qqnt-liuli-theme` 目录和 SnowLora 配置文件。
2. 在 QQ 设置 → SnowLora → 插件管理 → 本地安装中选择交付的 `qqnt-liuli-theme-1.3.5+snowlora.6.zip`，然后重启 QQ。也可把 ZIP 内容解压到 SnowLora 的 `assets/qqnt-liuli-theme/`，确保 `snowlora-plugin.json` 和 `load.js` 位于该目录根部。
3. 在 QQ 设置 → SnowLora 检查插件版本为 `1.3.5+snowlora.6`，在 QQ 设置 → 琉璃检查配色页出现基色选项。
4. 原有 `localStorage` 设置不会清空。新增 `liuli-color-source` 只保存模式和 HEX；选择自动模式时保留最后的手动 HEX，点击「恢复默认」才删除该项。

## 已完成的非实机检查

- 所有 `renderer/*.js` 通过 `node --check`；`load.js` 按 SnowLora 的 async-script 包装方式通过语法解析；`git diff --check` 通过。
- Chromium 合成界面中，导航让位后会话列表左边界移动 66 CSS px；短正文「签到」的 TG 消息，头衔仍有约 100px、整个名字行约 190px，不再缩成图标宽度。
- 在合成界面把透明度设为 `0.15`：上一版浮层的 `:root` 令牌仍按默认 `0.55` 算成约 `0.73`；现在同一滑块值算成 `0.33`。嵌套搜索结果不再增加第二个背景滤镜。顶部模拟中，横向划过未展开，向上靠近 60ms 左右展开，鼠标移开后收起；资料胶囊左边距为 8 CSS px。
- 合成界面中输入区的模糊 0px 与 18px 截图存在可见像素差异；伪元素滤镜从 `none` 变为 `blur(18px)`，编辑区背景保持透明且文字仍可见。文字气泡滤镜上限为 12px。这只验证 CSS 传递链，不代表 QQ 实机滤镜性能。
- 群成员标题和搜索入口在浏览器模拟的 100%、125%、150% 设备缩放下未互相覆盖；这不等于 Windows 系统缩放验收。
- 置顶分组每轮的 `getBoundingClientRect()` 调用点从 8 处减为 3 处，移除一块随滚动更新的底板；群公告重绑定复用既有页面观察器。会话切换的最长 1.5 秒逐帧查询改为现有页面变更事件唤醒，消息滚动位置未稳定时才短暂复查。顶部唤出的整页 `padding-top` 动画已移除。这些是静态与合成环境对比，**不是** QQ 实机 FPS 或 GPU 基准测试。

## 回退

1. 退出 QQ。
2. 在 SnowLora 插件管理中安装之前备份的 ZIP，或把备份的 `assets/qqnt-liuli-theme` 目录放回原位。
3. 重启 QQ，检查 SnowLora 插件版本回到备份时的版本（例如 `.5` 或 `.4`）。旧版本忽略新增的 `liuli-color-source`；如需完全清除这项新设置，只删除该 localStorage 键。不要清空其它琉璃设置或 QQ 数据。

匿名化录屏、真实聊天内容、账号信息和调试截图不应提交到仓库。发现问题时可导出不含截图的诊断包并附上不含个人信息的复现步骤。
