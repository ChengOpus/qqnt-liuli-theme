# 琉璃 UI 改版：部署与验收

适用目标：Windows QQ 9.9.36-53644（64 位）、SnowLora 0.3.0+。本轮测试版本：`1.3.5+snowlora.8`。

## 具体行为

| 区域 | 实现 |
| --- | --- |
| 输入栏 | 从原先的布局占位改为消息区上的绝对定位浮层；消息区延伸到输入栏后方。实际输入高度驱动列表末尾留白，最后一条消息仍可滚到输入栏上方。磨砂只画在伪元素上，编辑器本身不加滤镜。 |
| 顶部左右控件 | 左侧资料只给会话列让位，右侧窗口控件只给聊天列让位；不再共同推下整页。仍保留关闭角快速唤出、鼠标方向判断和子窗口保持展开。布局在状态变化时更新一次，短暂的位移动画由 WAAPI 完成。 |
| 创建群聊 | 清除浅色和深色下的整窗压暗；原生遮罩仍接收外部点击。删除误把 `.q-dialog .q-dialog-main` 打成透明的旧规则，真正的对话框本体使用玻璃材质。 |
| 群资料 | 识别 `group-info`、`group-profile` 等资料容器及独立资料路由。由最外层拥有一层磨砂，内部背景、描边与重复标签底色变轻；移除资料窗底下的第二层辅助窗口材质。实际 QQ 的全部资料卡变体仍需实机核对。 |
| 搜索建议 | 恢复真正的背景模糊。搜索列表显示时，原会话列表暂时不可见且不接收点击；节点和滚动位置保留，关闭搜索后恢复。独立综合搜索继续使用单独窗口作用域。 |
| 会话与置顶 | 会话列去掉整块圆角玻璃外框；选中态改为单层淡强调色。修复置顶开关的空属性和值为 `1` 的选择器不匹配。保留「置顶」标题、横线和图钉，不显示数量和折叠入口；淡底色开关单独生效。标题随首行滚动。 |
| 配色 | 所有区域使用同一个主题调色盘，支持 HSV、HEX、RGB、六种预设；不再弹出原生 `input[type=color]` 面板，不再显示主色／次色／第三色分段选择。主题自动取色、手动颜色、各区域独立选色、磨砂模式和恢复功能均可使用。 |
| 材质与动画 | `surfaces.js` / `surfaces.css` 统一负责面板、浮层、搜索和输入区的材质所有权；减少旧布局规则中的重复覆盖。弹出、设置切换、工具菜单和调色盘收起均有过渡，并响应系统减少动画选项。 |

材质的颜色来自当前主题亚克力色，透明度由现有滑块驱动；模糊仍使用 `--ll-material-blur`。文字气泡保留 12px 模糊上限；原生消息皮肤和媒体消息保留各自的渲染路径。连续会话列无需额外磨砂，避免每层容器都画一张玻璃。

## 颜色预设与配置兼容

六个预设来自 [Catppuccin 官方色板](https://github.com/catppuccin/palette) 的 Mocha 方案（读取的公开色板版本为 1.8.0，MIT）：雾蓝 `#89b4fa`、长春花 `#b4befe`、薰衣草 `#cba6f7`、樱粉 `#f5c2e7`、杏桃 `#fab387`、鼠尾草 `#a6e3a1`。插件内使用本地常量，打开调色盘无需联网。

- `liuli-dsh-settings`、壁纸和布局设置不会清空；旧 `pinCollapsed` 值被忽略。
- `liuli-color-source` 保留自动／手动模式、HEX 及精确色设置。
- `liuli-color-roles` 保留旧角色字段以兼容回退，并新增 `custom` 对象保存各区域的 HEX。升级不会提前改写旧配色；选择新颜色时才保存。旧版本忽略 `custom`，重新升级仍可读取。

## 安装、核对与回退

1. 退出 QQ，备份当前 `assets/qqnt-liuli-theme` 目录和 SnowLora 配置。
2. 在 SnowLora 插件管理中本地安装 `qqnt-liuli-theme-1.3.5+snowlora.8.zip`，或解压并替换主题目录。`snowlora-plugin.json` 与 `load.js` 应在主题目录根部。
3. 重启 QQ，在 SnowLora 中确认版本为 `1.3.5+snowlora.8`。配色页点击色块应出现带六个圆形预设的新调色盘。
4. 需要回退时退出 QQ，恢复备份目录或安装上一版 `.7` ZIP，再重启。不要清空 QQ 数据或全部 localStorage。

## 已执行的浏览器回归

`tests/ui-regression.cjs` 启动完整的资源包和 renderer，在仓库自带的匿名 QQ 结构 fixture 中测试；不会访问 QQ 账号、协议或聊天数据库。它覆盖实际设置事件和模块初始化，不预先手写主题属性来代替运行结果。

通过的组合为 1280×860 / 100% / 浅色，1920×1080 / 125% / 深色，900×680 / 150% / 浅色。这里的比例是 Chromium 设备缩放，不代表 Windows 系统缩放。

检查包括：

- 左右顶部各自让位；另一列不跟随下沉。
- 输入栏实际为绝对定位，距离底边 14 CSS px；消息视口延伸到其后方，最后一条消息仍能滚到它上方；编辑区仍可输入。
- 置顶开关、淡底色开关、轻量标题与取消折叠入口。
- 搜索有 18px 背景模糊，底层原会话文字隐藏；关闭后原列表恢复。
- 创建群聊的原生遮罩为全透明，同时对话框本体具有磨砂背景。
- 群资料外层材质、透明内层、独立资料路由识别。
- 自定义调色盘保存 HEX 到原配置，强调色随之变化；Esc 先关闭调色盘，设置弹窗仍可操作。
- 通过实际模糊滑块的 input 事件切换 0px / 18px，输入栏后方的条纹由清晰变模糊；匿名截图有可见像素差异。
- 无 renderer 未捕获异常；所有 renderer 脚本、SnowLora async-script 入口通过语法检查，ZIP 可完整解压。

开发环境可安装 Playwright 后运行：

```sh
npm install --no-save --package-lock=false playwright
CHROMIUM_PATH=/usr/bin/chromium node tests/ui-regression.cjs
```

匿名截图与结果输出到被忽略的 `out/ui-qa/`，不提交到仓库。新增模块复用原页面／尺寸观察器，没有新增 MutationObserver、逐帧常驻任务或定时轮询；置顶只有现有列表变化信号触发的同步，通常直接读取原生占位高度。这里没有 QQ 实机 FPS、GPU 或内存基准数据。
